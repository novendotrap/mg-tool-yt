mg-tool-yt
=========

Prerequisitos
-------------

- Tener instalado Python (recomendado Python 3.8+). Asegurarse de que python esté disponible en el PATH.

Instalación
-----------

En Windows la forma más sencilla es ejecutar el instalador de dependencias incluido:

- Abrir y ejecutar `install_requirements.bat` (doble clic o desde PowerShell/CMD).

Alternativa manual:

```powershell
pip install -r requirements.txt
```

Ejecución
---------

Para iniciar las herramientas use el lanzador incluido:

- Ejecutar `run_mg_tools.bat` (doble clic o desde PowerShell/CMD).

Alternativa (directa):

```powershell
python run.py
```
